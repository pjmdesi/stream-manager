## Thumbnail editor

- Stroke width and the filter sliders' value boxes use the standard +/- number field like the rest of the properties panel. Filter spinners step finer than their sliders (rough in with the slider, refine with the spinner — e.g. Brightness slides in 0.05s, spins in 0.01s), with no floating-point residue.
- Layer bounds on the canvas: hovering an element outlines it (and highlights its row in the layers panel — and vice versa), and every member of a group selection gets a dashed outline so elements inside the group frame stay identifiable even when one engulfs another. Outlines hide during drags/resizes so they never obscure edges while positioning.
- Letter case control for text layers (as typed / UPPERCASE / lowercase / Title Case). Non-destructive: the transform applies at render time — including to merge-field content — so switching back to "as typed" always recovers the original text.
- Preview mode: an Edit/Preview toggle above the layers panel swaps the canvas for mockups of real YouTube surfaces (home card, search result, suggested rail, compact row) with duration/LIVE/Upcoming badges (radio icon like YouTube's), watched-progress bar, and a light-theme toggle. The properties panel stays live — tweak a font size and watch every mockup size update. Badge/theme choices persist while toggling between Edit and Preview. Uses your Streamer Name setting for the channel line.
- Fixed: exported PNGs could include the new selection-bounds outlines when a group selection was active at save time.
- Gradient fills for shapes **and text**: a Solid/Gradient toggle on the Fill control with two color stops (per-stop transparency supported — fade-outs work), a stop-position field per stop, an angle field (0° = top-to-bottom), and a live vertical preview bar with a transparency checker. Blends interpolate in oklch by default so saturated color pairs stay vivid instead of graying out mid-blend; an sRGB option matches classic CSS blending for brand-guide parity. Gradient stops are full color fields, so palette drag-apply and the popover work on them too.
- Color fields: press Esc in the opacity field to clear a color to fully transparent, or in the hex field to reset it to black. (This replaces the clear button, which was redundant with the opacity control sitting right beside it.)
- Hex entry is more forgiving: paste or type any common form — `f00`, `f00c`, `ff0000`, `#ff000080`, with or without the `#` — and it normalizes when you click away. Entries that can't be a color are flagged inline instead of being silently discarded.
- Color palette panel in the editor sidebar: default swatch set to start, add your own with + (or promote a recently-used color from the recents row). Apply colors by dragging a swatch onto any color field, or keyboard-friendly via the palette button on every color field (popover with palette + recents). Edit mode (pencil) manages the palette: click to select (Ctrl/Shift for multiples), drag to reorder (multi-selections move as a block), delete selected, reset to defaults, and export/import the palette as a .json file. The palette is saved beside your library (`_palette.json`) so it follows your streams through cloud sync; recent colors are remembered per machine.
- Gradients are palette citizens too: editing a gradient captures it into the recent colors row as a swatch that shows the real stops, angle, and blend space, and clicking it saves it to the palette (palette export/import carries gradients along). Apply one by dragging it anywhere onto a Fill control (works on solid fills too — it switches them to gradient), or from the palette popover: the fill field's popover lists gradients alongside colors, and in gradient mode a palette button next to the Solid/Gradient toggle opens the gradient swatches. The reverse works too — drop a solid swatch onto a gradient Fill control to replace the gradient with a flat fill (dropping it on a stop's color field still just recolors that stop).
- Smarter recents: while you keep tweaking one color property, its recents entry updates in place instead of spawning a new swatch per tweak — five hue nudges use one slot, not five. Selecting a different layer "locks in" the entries; the next edit starts a fresh one.
- Swatches now capture the whole color: a saved or recent swatch includes its transparency, and applying one applies that transparency too — what you see in the tile is exactly what the field gets.
